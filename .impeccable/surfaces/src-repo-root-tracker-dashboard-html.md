# Surface brief: dashboard (list, board, detail)

Scope: whole dashboard.html. Modes: board = Experience; list and detail = Operate. User pinned the world (yohaku no bi, one bonsai per repo); the direction roll (seed 8aee4adb) does not override a pinned brief. Fused donors: generative-parametric-identity (seed derives each tree), alphabet-storm (ink as matter, raised into ink-on-night).
Constraints: no build step, no network, tests stay green (accent #b9d891 and dark scheme pinned). The user is the only user, is not color blind, and wants colorful creativity: every git state has its own hue.

## Direction contract

THESIS: Emptiness is the layout's main material (ma). Every repo is a bonsai whose form is seeded by its path and whose state is expressed by weather around it, never by chrome. Refuses: card grids, boxed panels, colored edge stripes, dashboard-gray.

OWN-WORLD: Night garden in sumi. Ink-black-green ground, paper grain, a fixed mist veil; raked moonlit gravel as the isometric floor (no slab walls, fading into the void) with rake rings around each pot; one ink ensō behind the board. Matcha (#b9d891) is the live accent and selection. One hue per state: gold = clean (sparkle, disc, "all calm" title), orange = local changes (falling leaves), blue = ahead/behind (motes), lilac = stale (dead branches, dotted ring), slate = unavailable (dashed ring, empty pot), vermilion = blockers and conflicts only (carved, pitted hanko seals; kintsugi crack). Dormancy is moss on the gravel and a desaturated canopy. Mincho display (Hiragino/Yu), quiet gothic text, one brush-stroke underline as the only ornament.

STORY: Glance and read the garden: still, pruned trees are well; leaves fall where work is uncommitted; motes drift for ahead/behind; dead wood for stale branches; a seal for blockers. Select a tree and the rest recede into mist; open it and its bonsai becomes the header of its detail page. When the last dirty repo goes clean, the island blooms gold.

FIRST VIEWPORT: Board: a borderless stage fading into the void, the active island's raked bed centered inside the ensō with the island name below it, trees at rest with slow sway, state discs beside each pot, a single margin-note inspector at right (272px), controls reduced to quiet text. List: an 820px column, a 44px mincho title, repos as sparse rows led by a 58px bonsai glyph; freshness noise only on hover or focus.

FORM: Seeded ink-brush bonsai (8 styles from the path hash: chokkan, moyogi, shakan, bunjin, hokidachi, sokan, kengai, fukinagashi), position 1 of the user-pinned brief, seed key 8aee4adb. Isometric pitch 156x78.
